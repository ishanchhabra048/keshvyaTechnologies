# Agency Portfolio Website

Premium portfolio for the agency built with React (Vite) and Node.js (Express).

## Prerequisites
- Node.js 20+
- MongoDB instance (local or Atlas)
- Cloudinary account
- SMTP provider

## Setup
1. `npm run install:all`
2. Copy `.env.example` to `.env` in `server/` and `client/` and fill variables.
3. `npm run dev` starts both client and server concurrently.
4. `npm run test` runs tests across both workspaces.
